About this app

A simple, private replacement for the paper attendance book.

This app records which students came to the work aid program each day. It replaces the paper process: you keep one master list of students, tick off the ones who attended, and the records are grouped by month.

How it works

  • Students — add every student once. This list is reused every day, so names are never re-typed.
  • Dashboard — create a month, then open it to add daily records.
  • Month page — add, edit or delete a day’s record, and print the whole month as a PDF.
  • Print Record — downloads a landscape A4 sheet with student names down the side, the days of the month across the top, and a tick where each student attended.

What is recorded

Only two things: student names and the dates they attended. No hours, notes or other fields.

Privacy & security

Access is protected by Firebase Authentication (email + password). Only accounts registered as admins can sign in — anyone else is told “This account is not a registered admin.” Firestore security rules stop anyone but a registered admin from reading or writing the data, so the database is never open to the public.

Changing the look

All colours live in CSS variables at the top of css/style.css. Your school name, program name and logo are set in js/config.js, so you can match the app to your school branding in seconds.
