Owner only · one-time tool

Convert my old records

This tool turns every old month into a record with the month's name as its title (for example “November 2026”), keeping all the dates and students inside it. Run it once. It is safe to run again.

Make sure your admin record has role = owner in the Firebase Console first. Then press the button and wait for the log to say “Conversion finished”. Nothing is removed until its new record has been saved.
